Context

Watchlist checks sometimes involved ID information written in non-Latin scripts. I wrote an SOP that uses generative AI to translate or transliterate that information, with a person reviewing every result before it is used.

SOP designGenerative AICompliance

How it works

  1. 1 · InputID data in a non-Latin script
  2. 2 · AITranslation or transliteration, first pass
  3. 3 · Human reviewA person checks the result against the source
  4. 4 · UseOnly then does it enter the operational check

Illustrative: Кеннет Росалес → Kennet Rosales → confirmed by a reviewer

The principle: AI speeds up the first pass; the SOP defines exactly where a person has to confirm.

05Approach

How I work, in five habits.

Trained as an industrial engineer: I look at work as a process, find where it gets stuck, and make that part easier to run.

01

Make the work visible

Trackers, dashboards and one place to look. If a team can't see the backlog, it can't manage it.

02

Write it down

SOPs, escalation paths and handoffs that a new teammate can follow on day one.

03

Measure what matters

SLA, quality, error rate, backlog and staffing: few numbers, read every week.

04

AI, with a human in the loop

ChatGPT, Claude and Claude Code for the first pass; a person for the decision.

05

Close the loop

Follow up until it's done, not until it's sent.

—

This site, too.

Designed and built with Claude Code; the film was made with HyperFrames. Same rule: AI drafts, I decide.
