# Design — Kenneth Rosales

Shared with the portfolio site (`../index.html`).

| Token  | Value     | Use                         |
| ------ | --------- | --------------------------- |
| ink    | `#0C0C0B` | background                  |
| ink-2  | `#161614` | raised surfaces             |
| line   | `#2A2926` | rules, inactive dots        |
| mute   | `#8C887F` | secondary text, mono labels |
| paper  | `#ECE8DF` | primary text                |
| gold   | `#C9A46A` | the one accent: the signal  |

Type: **Instrument Serif** (display, italic for the emphasized word), **Inter** (body), **JetBrains Mono** (micro labels, uppercase, +0.18em tracking).

Motion: calm and exact. `power3.inOut` / `expo.out`; no bounce, no elastic. One accent moment per scene.
